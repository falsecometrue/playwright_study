# 画面仕様：コメント投稿の入力検証

## URLとタイトル

- URL：`/01_low/03-comment-validation/`
- document.titleとh1：`コメント投稿の入力検証`（概要などへの遷移後は別タイトル）
- 共通ヘッダー：TubeLab。ローカルの学習用動画サイト。

## 前提条件・初期状態

表示名・コメント・結果・エラーは空。コメントはtrim後3〜100文字。

## 要素の識別

| プロパティ | 役割またはラベル | 検索する名前 |
| --- | --- | --- |
| `author` | label | 表示名 |
| `comment` | label | コメント |
| `submit` | button | コメントを投稿 |
| `error` | alert | 名前指定なし |
| `result` | status | 名前指定なし |

同じ役割・名前が複数ある場合は動画の行、region、iframeで絞ります。getByRoleは座標を使って識別しません。

## 操作・状態遷移・期待結果

1. 表示名が空の場合「表示名を入力してください」となり、投稿されないこと。
2. コメント2/3/100/101文字の境界を検証する。
3. 空白だけのコメントは3文字未満として拒否されること。
4. 入力を修正して再投稿し、エラーが消え、表示名付きのコメントが表示されること。
